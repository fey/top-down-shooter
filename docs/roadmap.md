# Top-Down Shooter — план и роадмап

## Контекст

Делаем небольшой браузерный прототип top-down шутера — игру на вечер-два, чтобы поймать ощущение геймплея. Это новый проект с нуля. Цель — рабочий прототип, а не продукт: один уровень, базовая стрельба, два врага, два оружия.

## Согласованные требования

- **Жанр:** top-down shooter (вид сверху).
- **Масштаб:** прототип, одна статичная карта.
- **Технологии:** Phaser 3, TypeScript, сборка через Vite, линт/формат — Biome.
- **Управление:** WASD — движение, мышь — прицеливание, ЛКМ — стрельба, цифры/колесо — смена оружия, R — рестарт на экране конца.
- **Уровень:** одна статичная карта с несколькими комнатами, соединёнными проходами. Враги расставлены вручную.
- **Win condition:** зачистить всех врагов на карте.
- **Lose condition:** HP игрока ≤ 0.
- **Арсенал:** пистолет (средний урон, средний темп, точный) + дробовик (высокий урон в упор, разброс).
- **Враги:** melee (бежит на игрока, бьёт в упор) + shooter (держит дистанцию, стреляет пулями).
- **Game feel:** HP у игрока (например, 5), ограниченные патроны на оружие, пикапы (аптечки + ящики с патронами) расставлены на карте.
- **Графика:** спрайты из бесплатного пака Kenney (Top-down Shooter / Tanks / Topdown Shooter).
- **Состояния:** Boot/Preload → MainMenu → Game → GameOver (с кнопкой "Заново").

## Стек и структура

- **Phaser 3** через npm (`phaser`).
- **TypeScript** — строгий режим (`strict: true`), типы для всех сущностей и конфига.
- **Vite** для dev-сервера и сборки (быстрый HMR, нативная поддержка TS).
- **Biome** для линта и форматирования (вместо ESLint + Prettier) — один конфиг `biome.json`, скрипты `biome check` / `biome format`.
- **Без бэкенда** — игра работает локально из статичных файлов.

```
top-down-shooter/
  index.html
  package.json
  tsconfig.json
  vite.config.ts
  biome.json
  public/
    assets/
      sprites/        # спрайты Kenney
      audio/          # (опционально) звуки выстрелов
  src/
    main.ts           # точка входа, конфиг Phaser
    scenes/
      BootScene.ts    # настройка
      PreloadScene.ts # загрузка ассетов с прогресс-баром
      MainMenuScene.ts
      GameScene.ts    # основная игровая сцена
      GameOverScene.ts
      HUDScene.ts     # оверлей: HP, патроны, счётчик врагов
    entities/
      Player.ts
      Enemy.ts        # базовый класс
      MeleeEnemy.ts
      ShooterEnemy.ts
      Bullet.ts
      Pickup.ts
    weapons/
      Weapon.ts       # базовый класс
      Pistol.ts
      Shotgun.ts
    level/
      level1.ts       # описание уровня (стены, спавны врагов, пикапы, точка старта)
    config.ts         # числовые параметры (HP, урон, скорости)
```

## Ключевые компоненты

**GameScene** — основная сцена. Создаёт игрока, врагов, стены (статичная физическая группа), пикапы, пули. Управляет коллизиями: пули↔враги, пули↔стены, игрок↔враги (melee), пули врагов↔игрок, игрок↔пикапы. Слушает события смерти врагов; когда счётчик живых врагов = 0 — переход в GameOver (победа). При смерти игрока — переход в GameOver (поражение).

**Player** — спрайт с Arcade Physics body. Движение через нормализованный вектор от WASD (одинаковая скорость по диагонали). Поворот по направлению на курсор. Хранит HP, текущее оружие, инвентарь патронов на каждое оружие. Делегирует выстрел текущему `Weapon`.

**Weapon (Pistol / Shotgun)** — общий интерфейс: `tryFire(scene, owner, targetVec)`. Внутри — кулдаун, расход патрона, спавн пули(пуль) из общей группы. Дробовик спавнит N пуль с разбросом по углу.

**Enemy** — базовый класс с HP, спрайтом, физикой, AI tick. `MeleeEnemy` идёт к игроку, наносит контактный урон с кулдауном. `ShooterEnemy` подходит на дистанцию, останавливается, стреляет в игрока с задержкой. Простой LoS через `Phaser.Geom.Line` + проверка пересечения со стенами.

**Bullet** — короткоживущий спрайт, движется с заданной скоростью, уничтожается при коллизии или по таймеру/выходу за границы. Две группы: пули игрока и пули врагов.

**Pickup** — спрайт, у которого `kind` ∈ {health, ammo_pistol, ammo_shotgun}. При оверлапе с игроком применяет эффект и удаляется.

**HUDScene** — отдельная сцена-оверлей, чтобы не путать игровой и UI-рендер. Подписывается на события из `GameScene` (например, через `scene.events.emit('hpChanged', hp)`).

## Уровень

Один файл `level/level1.ts` экспортирует:
- список прямоугольников-стен (x, y, w, h);
- стартовую позицию игрока;
- список спавнов врагов (type, x, y);
- список пикапов (kind, x, y).

`GameScene` читает этот объект и расставляет всё на старте. Карта — несколько комнат, соединённых коридорами, чтобы LoS-логика стрелков имела смысл.

## Game loop и баланс (стартовые числа)

- Игрок: HP 5, скорость 200 px/s.
- Пистолет: 1 урон, кулдаун 250 мс, скорость пули 600, запас 60.
- Дробовик: 5 пуль по 1 урону, разброс ±15°, кулдаун 700 мс, запас 20 выстрелов.
- Melee enemy: HP 2, скорость 140, контактный урон 1, кулдаун 600 мс.
- Shooter enemy: HP 2, скорость 80, дистанция стрельбы 350 px, кулдаун выстрела 1200 мс, урон 1.
- Пикапы: аптечка +2 HP, ящик патронов — заданное количество.

Все числа держим в `src/config.ts`, чтобы быстро твикать.

## Декомпозиция на вехи

Каждая веха — отдельный коммит/PR, заканчивается рабочим билдом, который можно открыть в браузере и проверить руками. Следующая веха строится поверх предыдущей.

### M1. Скелет проекта
- `npm init`, установка `phaser`, `typescript`, `vite`, `@biomejs/biome`.
- Конфиги: `tsconfig.json` (strict), `vite.config.ts`, `biome.json`, `package.json` со скриптами `dev/build/check/typecheck`.
- `index.html`, `src/main.ts` с минимальной Phaser-игрой (пустая сцена с цветным фоном).
- **Verify:** `npm run dev` открывает страницу с пустой сценой, `check`/`typecheck` зелёные.

### M2. Игрок и движение
- `BootScene` + `PreloadScene` (заглушка ассетов или цветной прямоугольник).
- `GameScene` с игроком: WASD движение (нормализованный вектор), поворот к курсору.
- Границы мира, простые стены-прямоугольники (статичная физика), коллизия игрок↔стены.
- **Verify:** игрок бегает по карте, упирается в стены, поворачивается на курсор.

### M3. Стрельба и пистолет
- `Bullet` (группа пуль игрока).
- `Weapon` базовый класс + `Pistol`: ЛКМ — выстрел, кулдаун, спавн пули в направлении курсора.
- Коллизия пуля↔стена (удаление), TTL на пулях.
- **Verify:** ЛКМ стреляет пулями, пули летят и гаснут на стенах.

### M4. Враги: melee
- `Enemy` базовый класс, `MeleeEnemy` с простым AI (двигаться к игроку).
- Коллизия пуля↔враг, HP врага, смерть.
- Контактный урон врага игроку с кулдауном, HP игрока, смерть игрока (пока — console.log).
- **Verify:** melee-враги бегут к игроку, ловят пули и умирают, бьют игрока при контакте.

### M5. Враги: shooter
- `ShooterEnemy`: подходит на дистанцию, останавливается, стреляет пулями врагов.
- Группа пуль врагов, коллизия пуля врага↔игрок, пуля↔стена.
- Простой LoS — проверка пересечения линии со стенами перед выстрелом.
- **Verify:** shooter держит дистанцию, стреляет, его пули наносят урон игроку.

### M6. Второе оружие и переключение
- `Shotgun`: N пуль с разбросом, больший кулдаун.
- Переключение оружия (1/2 или колесо мыши).
- Ограниченные патроны на каждое оружие, расход при выстреле.
- **Verify:** обе пушки работают, переключение, патроны тратятся.

### M7. Уровень и пикапы
- `level/level1.ts`: данные карты (стены, спавны врагов, пикапы, точка старта).
- `Pickup` с типами `health`, `ammo_pistol`, `ammo_shotgun`, оверлап с игроком.
- `GameScene` собирает всё из данных уровня.
- **Verify:** загружается полноценная карта с расставленными врагами и пикапами; пикапы работают.

### M8. UI, состояния, рестарт
- `MainMenuScene` со стартом, `GameOverScene` с двумя текстами (победа/поражение) и кнопкой "Заново".
- `HUDScene` поверх игры: HP, патроны текущего оружия, счётчик оставшихся врагов.
- Триггеры: 0 HP → GameOver(lose), 0 живых врагов → GameOver(win).
- **Verify:** полная петля Меню → Игра → GameOver → Меню работает.

### M9. Ассеты Kenney и полировка
- Подключение спрайтов Kenney (игрок, враги, оружие, пули, пикапы, тайл-стена).
- Замена цветных прямоугольников на спрайты.
- Балансировка чисел в `config.ts` по ощущениям.
- **Verify:** игра выглядит как top-down shooter, ощущается играбельно.

## Верификация прототипа целиком

- `npm run dev` поднимает Vite, игра открывается в браузере.
- `npm run check` (Biome) — линт и формат проходят без ошибок.
- `npm run typecheck` (`tsc --noEmit`) — типы валидны.
- Стартовый экран → нажатие "Старт" → игровая сцена.
- WASD двигает игрока, мышь поворачивает, ЛКМ стреляет, цифры 1/2 переключают оружие.
- Пули останавливаются на стенах, убивают врагов.
- Melee враги догоняют и бьют; shooter враги останавливаются и стреляют.
- Пикапы подбираются и применяют эффект (HP/патроны).
- При HP = 0 → GameOver (поражение), при 0 живых врагов → GameOver (победа).
- Кнопка "Заново" перезапускает GameScene.

## Что НЕ входит в прототип

- Сохранения, прогрессия между запусками.
- Звук (можно добавить, но не блокер).
- Несколько уровней, меню выбора уровня.
- Анимации спрайтов (используем статичные спрайты Kenney).
- Мобильное управление, геймпады.
- Сложная навигация врагов (pathfinding) — обходимся прямым движением + остановкой у стен.
