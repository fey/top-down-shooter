# Test Levels Design

**Date:** 2026-05-27  
**Status:** Approved  

## Context

Игра имеет один боевой уровень (`level1`) и пустой `level2`. Для ручного тестирования
поведения врагов нужны изолированные сценарии: каждый уровень проверяет одну систему
в чистых условиях, без «шума» от остальных механик.

## Цели

- Изолировать и быстро воспроизводить поведение каждого типа врага
- Проверить pathfinding в нетривиальных топологиях
- Проверить pack alerts на смешанных группах
- Все уровни доступны через LevelSelectScene без дополнительных ключей сборки

---

## Уровни

### level2 — Solo Melee *(перезапись существующего пустого)*

**Задача:** изолированное поведение одного melee-врага.  
**Геометрия:** открытое поле, только стены-периметр, никаких внутренних препятствий.  
**Враги:** 1 melee в центре карты (960, 540).  
**Игрок:** (200, 200).  
**Что наблюдаем:** aggro, переход IDLE→CHASE→ATTACK, dodge при прицеливании игроком, slot positioning при единственном враге.

---

### level3 — Solo Shooter *(новый)*

**Задача:** изолированное поведение одного shooter-врага.  
**Геометрия:** открытое поле + 2 горизонтальных укрытия в центральной части (дают shooter возможность прятаться, игроку — использовать cover для теста SEARCH).

```
Стены-укрытия:
  { x: 800, y: 400, w: 300, h: 32 }   // нижнее укрытие
  { x: 1100, y: 680, w: 300, h: 32 }  // верхнее укрытие
```

**Враги:** 1 shooter на (1600, 540).  
**Игрок:** (200, 200).  
**Что наблюдаем:** LoS-check, кайтинг (retreat/advance), переход в SEARCH когда игрок за укрытием, возврат в SHOOT при восстановлении LoS.

---

### level4 — Pathfinding Maze *(новый)*

**Задача:** стресс-тест A*-навигации в сложной топологии.  
**Геометрия:** 4 вертикальных перегородки с чередующимися проходами — враги стартуют за разными стенами и вынуждены огибать их по разным маршрутам.

```
Перегородки (ячейки 64px):
  { x: 480,  y: 600, w: 32, h: 800 }  // оставляет проход сверху
  { x: 800,  y: 480, w: 32, h: 800 }  // оставляет проход снизу
  { x: 1120, y: 600, w: 32, h: 800 }  // оставляет проход сверху
  { x: 1440, y: 480, w: 32, h: 800 }  // оставляет проход снизу
```

**Враги:** 4 melee, по одному за каждой перегородкой (x≈570, 890, 1210, 1530; y=540).  
**Игрок:** (200, 540) — слева, враги должны огибать стены по зигзагу.  
**Что наблюдаем:** корректность A*-маршрутов, отсутствие застреваний в углах, перестройка пути при блокировке другим врагом.

---

### level5 — Melee Dojo *(новый)*

**Задача:** групповой бой melee — slot positioning, одновременная атака, dodge.  
**Геометрия:** несколько колонн-препятствий создают небольшое укрытие, но в целом открытое пространство.

```
Колонны:
  { x: 700,  y: 350, w: 96, h: 96 }
  { x: 1100, y: 350, w: 96, h: 96 }
  { x: 700,  y: 730, w: 96, h: 96 }
  { x: 1100, y: 730, w: 96, h: 96 }
```

**Враги:** 6 melee, расставленных по дуге в правой половине карты.  
**Игрок:** (200, 540).  
**Что наблюдаем:** система слотов атаки (не все враги атакуют одновременно), dodge при прицеливании, pack alert когда агрессируется первый враг.

---

### level6 — Shooter Range *(новый)*

**Задача:** несколько shooter-врагов с разными углами LoS и разными дистанциями.  
**Геометрия:** длинный горизонтальный коридор с двумя боковыми ответвлениями — создаёт T-пересечения, через которые shooter теряет/восстанавливает LoS.

```
Стены коридора:
  { x: 960, y: 300, w: 1700, h: 32 }   // верхняя стена коридора
  { x: 960, y: 780, w: 1700, h: 32 }   // нижняя стена коридора
  // боковые карманы (ответвления вверх)
  { x: 600,  y: 172, w: 32, h: 260 }
  { x: 900,  y: 172, w: 32, h: 260 }
  { x: 1200, y: 172, w: 32, h: 260 }
```

**Враги:** 4 shooter (x ≈ 700, 1000, 1300, 1600; y = 540).  
**Игрок:** (200, 540) — входит в коридор с запада.  
**Что наблюдаем:** многосторонний обстрел, кайтинг при разных дистанциях, SEARCH когда игрок заходит в боковой карман, взаимный pack alert между shooter'ами.

---

### level7 — Mixed Pack *(новый)*

**Задача:** pack alerts между разными типами врагов.  
**Геометрия:** открытое поле с одной L-образной стеной, за которой прячется смешанная группа.

```
L-образная стена:
  { x: 1100, y: 400, w: 600, h: 32 }   // горизонтальная часть
  { x: 1380, y: 560, w: 32, h: 352 }   // вертикальная часть
```

**Враги:** 3 melee (x≈1000/1200/1100; y≈500/480/600) + 2 shooter (x≈1500/1600; y=500/600).  
**Игрок:** (200, 540).  
**Что наблюдаем:** shooter агрессирует первым (он видит дальше), pack alert поднимает melee раньше чем те обнаружат игрока; melee rush, пока shooter кайтит сзади.

## Изменения в коде

### Файловая структура

```
src/level/
  level1.ts  (без изменений)
  level2.ts  (перезапись — Solo Melee)
  level3.ts  (новый — Solo Shooter)
  level4.ts  (новый — Pathfinding Maze)
  level5.ts  (новый — Melee Dojo)
  level6.ts  (новый — Shooter Range)
  level7.ts  (новый — Mixed Pack)
```

### LevelSelectScene.ts

Текущий массив `LEVELS` расширяется 5 новыми записями. Кнопки генерируются в цикле — добавление элемента в массив автоматически создаёт кнопку.

Клавиши 1–7 добавляются в `create()` по тому же паттерну что и 1–2 сейчас.

### Типы

`EnemySpawn` и `LevelData` уже поддерживают `"melee" | "shooter"` — изменений типов не нужно.

## Проверка (Verify)

1. `make check` — Biome не находит ошибок
2. `make typecheck` — TypeScript не находит ошибок  
3. `make dev` → открыть в браузере → LevelSelectScene показывает 7 кнопок уровней
4. По каждому уровню вручную:
   - Уровень загружается без ошибок в консоли
   - Враги появляются на ожидаемых позициях
   - Целевое поведение воспроизводится (см. «Что наблюдаем» выше)
5. ESC из GameScene возвращает в LevelSelectScene

## Вне скоупа

- Изменение игровой механики или AI
- Новые типы врагов
- Балансировка HP/урона
- Звук, визуальные эффекты
